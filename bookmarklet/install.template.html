Job Tracker — Quick Add Bookmarklet

Drag this button to your bookmarks bar:

➕ Add to Job Tracker

How to use it:
  1. Drag the button above onto your browser's bookmarks bar (make sure it's visible: Cmd+Shift+B on Mac).
  2. Go apply for a job as normal, on any site.
  3. On the job posting (or confirmation) page, click the bookmark.
  4. Confirm/edit the company and role it guesses from the page title, hit OK.
  5. It's added to your tracker, with the page URL saved as the Source link.

Note: this bookmarklet points at http://localhost:4000, so it only works while your backend is running locally. If you deploy the backend live, edit API_URL in bookmarklet/tracker.js, run node bookmarklet/build.js, and re-drag the updated button here.

If dragging doesn't work in your browser, right-click the button → "Copy Link" → manually create a new bookmark and paste it as the URL.
